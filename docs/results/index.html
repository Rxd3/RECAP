RECAP: restoring punctuation and casing in spoken English

Lowercased, unpunctuated transcripts of informal English speech go in; every word gets a label for the punctuation mark after it and, in mode C, its own casing. A hidden Markov model with Viterbi decoding against linear-chain CRFs, on splits where no video appears in both training and test.

Is it just the end of the utterance?

Every utterance ends in a period or a question mark. A shortcut that puts O everywhere and a period (or a question mark after a wh-word or auxiliary start) on the last word already reaches PERIOD F1 66.68 in mode A, against the HMM's 67.34. Dropping each utterance's last word shows what a model learns inside the sentence.

How these numbers were produced

Data and labels

  • SponSpeech reference transcripts (informal podcast-style English from YouTube), CC BY-NC 4.0; transcripts only, no audio.
  • Mode A: O, COMMA, PERIOD, QUESTION. Mode B adds EXCLAMATION, COLON, SEMICOLON, DASH. Mode C: mode A × LOWER, FIRST_UPPER, ALL_UPPER (12 joint labels).
  • Leak-free primary splits; a gold-noise audit flags leftover speaker labels (a third of validation COLONs), so COLON scores are an upper bound.

Models and settings

  • First-order HMM with Viterbi decoding, additive smoothing α = 0.01, chosen on validation.
  • Linear-chain CRF (CRFsuite, L-BFGS), c1 = c2 = 0.1, 100 iterations, not tuned. Basic features: ±1 window, affixes, shape, boundaries. Improved: adds the ±2 window, word pairs, question, clause, casing and position cues.
  • Each frozen model predicted each test list once.

Statistics

  • 95% intervals: bootstrap over whole videos, 1,000 resamples, seed 2026; paired comparisons reuse the same resampled videos.
  • Holm step-down correction at α = 0.05 in two families: 21 test comparisons and 18 ablations.
  • Limits: one fit per setting (intervals cover test sampling only), CRF settings not tuned, rare mode B marks stay under 8 F1.

Reproduce

  • One command-line tool: pip install -e ".[dev]", then recap --help (Python 3.12+).
  • Every course-model number comes from a committed evaluator file under results/scores/; recap result-stats regenerates the Holm, cluster and audit summaries. The neural rows are score files of predictions that are not in the repository.
  • CI on Python 3.12 and 3.13: lint, type check, tests and a coverage gate.
