## What this repository holds

No dataset files are committed: `data/raw/`, `data/processed/` and `data/splits/` are ignored
by Git ([data/README.md](../data/README.md)). The release `sponspeech-m1-v2` is rebuilt from the
official archive with `scripts/prepare_data.py`, or shared by the team as an archive.

## Changes made to the source (CC BY-NC 4.0 asks that changes be indicated)

The release files are an adaptation of the SponSpeech transcripts:

- non-lexical strings (timecodes, non-speech and name tags, speaker labels) are removed and
  logged; tokens are lowercased after the casing label is extracted;
- punctuation is turned into per-token labels (modes A, B and C), casing into three classes,
  with masks for approximate casing;
- unresolved, low-comma and text-to-speech records are flagged, and new leakage-controlled
  ID lists are built.

The rules are in [DATASET_PLAN.md](DATASET_PLAN.md) and [DATA_CONTRACT.md](DATA_CONTRACT.md).
Anyone who copies a release must keep it non-commercial and ship
`SPONSPEECH_LICENSE_AND_ATTRIBUTION.txt` with it.
